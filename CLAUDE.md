# Осколки Бездны — заметки для Claude

Мобильная match-3 RPG (PoE-подобная) в браузере и как PWA. Репозиторий: crashic/A-A-A-A-RPG-Match-3, игра: https://crashic.github.io/A-A-A-A-RPG-Match-3/

## Правила работы с пользователем
- Отвечать по-русски, о себе в женском роде («сделала»).
- Если есть варианты, что делать дальше, предлагать их опросом (AskUserQuestion).
- Устройство: телефон 1080×2460, CSS ~360×820, управление касанием и перетаскиванием.
- После правок: проверить Playwright (viewport 360×820, без ошибок в консоли), закоммитить и запушить в main, GitHub Pages обновится сам. Одиночный файл для отправки: `python3 build.py`, затем `dist/abyss-shards.html`.

## Структура
См. README.md: стили в `css/style.css`, логика в `js/*.js` (классические скрипты с общей глобальной областью, порядок подключения в `index.html` важен). Читать и править только нужный файл. Новый js-файл добавлять в `index.html` и в список `sw.js` (поднять версию кэша).

## Ключевое устройство
- Поле: массив B из 64 клеток; значение v: цвет = v%10 (0..4 обычные, 5 череп), +10 бомба, +20 осколок, +100 заморожена.
- Сохранение: localStorage, ключ `abyss-shards-v2`; новые поля P нужно давать с дефолтом в `js/state.js`, старые сохранения подхватываются через Object.assign.
- Вкладки: hero, tree, inv, pet, atlas, shop, stats («Цели»), set («Опции»); отрисовка в `drawTab` (`js/ui.js`).
