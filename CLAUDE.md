# A-A-A-A Match 3 RPG — заметки для Claude

Мобильная match-3 RPG в браузере и как PWA. Репозиторий: crashic/A-A-A-A-RPG-Match-3, игра: https://crashic.github.io/A-A-A-A-RPG-Match-3/
С версии 0.1.0 игра делается с нуля (старый код «Осколков Бездны» удалён, он есть в истории git до коммита b3f1c1e).

## Правила работы с пользователем
- Отвечать по-русски, о себе в женском роде («сделала»).
- Выбор вариантов и пунктов меню — опросом (AskUserQuestion).
- Устройство: телефон 1080×2460, Android 13+, CSS ~360×820, управление касанием и перетаскиванием.
- Мелкая правка — «в файле X найди это, замени на это»; заметная — файлы целиком с путями; новая подсистема или много файлов — сначала спросить (архив или пуш).
- Перед крупной пересборкой проекта уточнять и объяснять, почему так рациональнее.
- В конце архива указывать версию.
- Перед выпуском СПРАШИВАТЬ пользователя опросом: какой номер версии присвоить и какой текст внести в список изменений (предложить варианты). Самой версию не выбирать и текст не вписывать.
- После правок: проверить Playwright (viewport 360×820, без ошибок в консоли), выставить согласованную `APP_VERSION`, добавить согласованную запись в `js/changelog.js`, закоммитить и запушить в main.
- Список изменений (`js/changelog.js`, открывается нажатием на версию): новая версия сверху, максимально коротко, только главное — «добавили 25 предметов», «создали систему квестов».
- Формат версии у пользователя свободный (например `0.1.a`); для обновления важна только смена строки, порядок номеров не важен.

## Дизайн
- Весь интерфейс и графика — по дизайн-системе пользователя: https://claude.ai/artifact/R918BS9sRLVB4Q6fLH64d4 (копия в `design/`: `README.md` — правила стиля, `tokens.json` — цвета/шрифты/отступы, `components/*/preview.html` — образцы кнопок, панелей, самоцветов, спецфишек, поля).
- Перед новой графикой читать `design/README.md` и нужный `design/components/<Имя>/`. Основной вариант фишек — самоцветы (`GemsElemental`), поле 7×7 (`BoardSample`), 6 стихий: огонь, вода, природа, свет, тьма, дух.
- Цвета только через переменные `css/tokens.css`; он генерируется: `python3 tools/build-tokens.py` (после правки `design/tokens.json`).
- Кнопки `.btn` + цвет: `green` — главное действие, `red` — выход/опасность, `orange` — награда, `purple` — магазин, `stone` — второстепенное; `round` — круглая иконка. Заголовок экрана — `.ribbon`, контейнер — `.panel`. Текст не ставить прямо на закатный фон — только на камне.
- Шрифты Russo One (заголовки, кнопки, цифры) и Nunito 600/800 (текст) лежат в `fonts/`, подключены в `css/fonts.css`.

## Структура
- Движок: HTML + CSS + JS, классические скрипты с общей глобальной областью.
- Каждая функция — отдельный файл в `js/`, имя файла = имя функции. Порядок подключения в `index.html` важен, `js/main.js` последний.
- Спрайты — в `sprites/`.
- Новый скрипт или стиль подключать в `index.html`, затем `python3 tools/update-sw.py` — он пересобирает список `FILES` в `sw.js` (скрипты, стили, шрифты, спрайты).
- Экраны — `<section class="screen">` в `index.html` (menu, profile, settings, game), переключение `showScreen(id)`; уход из меню пишется в history, «Назад» телефона возвращает в меню.
- Сохранения: 3 ячейки, ключи localStorage `aaaa-slot-1..3`, выбранная — `aaaa-active-slot`; настройки — `aaaa-settings`, новые поля добавлять в `DEFAULT_SETTINGS` (`js/state.js`).
- Версия — `js/version.js` (`APP_VERSION`); `sw.js` берёт её через importScripts, так что кэш и автообновление завязаны на неё.
