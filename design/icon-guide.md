# Как рисовать иконки

Конспект десяти уроков по игровым иконкам: книга с глазом, магический фолиант, кольцо с черепом, флакон, сундук с осьминогом, мешок золота, кнопка-монета, рубашка карты, кожаная сумка, стеклянный графин. Ниже — общий порядок работы, разбор материалов и как это переводится в SVG-набор этого проекта.

## Порядок работы (общий для всех уроков)

1. **Референсы.** Собрать 3–6 фото материалов (золотой слиток, кожа, череп, стекло, монеты) и 1–2 игровые иконки близкого стиля. Решить, из каких материалов состоит предмет.
2. **Эскиз линиями.** Простой контур в лёгкой перспективе сверху-сбоку (предмет повёрнут на ¾, видны две стороны и верх). Сразу утрирует пропорции: крупный главный элемент, толстые края.
3. **Проверка силуэта.** Залить силуэт одним цветом. Если предмет не узнаётся по тени (как графин в уроке) — переделать форму, а не детали.
4. **Локальные цвета.** Каждому материалу — свой плоский базовый цвет. Без света и теней.
5. **Источник света и большие объёмы.** Свет **сверху-слева**. Делим каждую форму на: блик → свет → полутень (терминатор) → собственная тень → **рефлекс** (отражённый свет снизу, холоднее основного) → падающая тень. Сначала крупные плоскости, потом мелочь.
6. **Фактура и детали.** Узоры на обложке, швы, царапины, сколы, трещины, древесные волокна. Деталей больше всего в центре внимания, к краям — меньше.
7. **Центр внимания.** Один фокус — глаз, кристалл, руна, череп. Там максимальный контраст, насыщенность и самый яркий блик. Всё остальное спокойнее.
8. **Общая коррекция цвета.** Тёплый свет — холодные тени (или наоборот), подкрутить насыщенность: слишком тусклое оживить, слишком пёстрое приглушить. Проверить, что светотень одна для всего предмета.
9. **Рефлексы и края.** Тонкий отражённый свет по нижним и задним краям отделяет предмет от фона.
10. **Эффекты.** Свечение (ореол цвета магии), искры-звёздочки на бликах, частицы, дым, капли. Эффекты — последний слой, они не заменяют объём.
11. **Подача.** Фон-подложка, рамка (круг или скруглённый квадрат), при необходимости подпись.

## Материалы

| Материал | Как рисуется |
|---|---|
| **Золото / металл** | Высокий контраст: почти белые острые блики рядом с тёмными тенями. Тени тёплые коричневые, рефлекс холодный (голубоватый или фиолетовый от окружения). Края скошены — на фаске узкий блик. |
| **Сталь / железо** | Серо-голубая, блики холодные и резкие, на углах потёртости светлее, в углублениях темнее. Заклёпки — маленькие сферы со своим бликом. |
| **Кожа** | Средний контраст, мягкие широкие блики, швы пунктиром, потёртости светлее по выпуклостям, складки темнее. Блик с лёгким голубым оттенком от окружения. |
| **Дерево** | Волокна вдоль формы, тёмные щели между досками, светлые сколы на рёбрах. |
| **Кость / череп** | Тёплая слоновая кость, тёмные глубокие впадины (глазницы, нос), сколы и трещины, блик неяркий. |
| **Стекло** | Почти прозрачное: сквозь него виден фон. Объём дают яркие блики по краям и рефлексы внутри, а не заливка. Края светлые, середина тёмная. |
| **Жидкость** | Свой объём внутри стекла, поверхность — светлая полоса. Бликов меньше, чем у стекла, цвет насыщеннее у дна. Можно наклонить — динамика. |
| **Камень** | Трещины, сколы светлее по рёбрам, мох или грязь в углублениях. |
| **Лава / магия** | Светится изнутри: трещины от жёлто-белого центра к оранжевому и тёмно-красному краю. Ореол вокруг. Сильный тёплый-холодный контраст с тёмным металлом. |
| **Ткань / верёвка** | Мягкие складки, у верёвки — повторяющиеся витки с маленьким бликом на каждом. |

## Кнопка по слоям (урок монеты)

1. Круг с мягкой обводкой (рамка).
2. Основа: градиент сверху светлее, внутреннее свечение.
3. Толщина: копия формы чуть меньше и смещена — получается борт.
4. Фактура: диагональные полосы и пятна внутри формы (обрезаны по контуру), едва заметные.
5. Символ: своя форма с внутренней тенью и фаской — будто выдавлен.
6. Блики дугами по краю сверху-слева и рефлекс снизу-справа.
7. Внешнее свечение.

## Урок монеты (подробно)

Разбор референса: **цвет** — сильный контраст, золото, яркие блики; **форма** — круг с толщиной; **детали** — отражённый свет, волнистые блики.

1. Круг-основа, заливка градиентом.
2. Внутренний круг меньше и темнее — ободок.
3. Символ ($, звезда, руна) с выдавливанием: светлый край сверху-слева, тень снизу-справа.
4. Толщина монеты: копия, сдвинутая вниз, темнее — видно ребро.
5. Тень от ободка на поле сверху-слева, отражённый свет снизу-справа.
6. Усиление контраста: тени насыщенно-оранжевые, блики почти белые.
7. Большой глянцевый блик-«волна» и яркие точки по краю.
8. Общее свечение. Та же схема даёт серебро и бронзу заменой цветов и стопку монет повтором со сдвигом.

## Стеклянные блики (набор наложений)

Последний слой поверх иконки или элемента интерфейса — «стекло». Одинаково работает на двенадцати формах — квадрат, круг, сквиркл, 6- и 8-гранник, щит, сердце, ромб, капля, арка, звезда, свиток; всегда обрезан по форме. Живые примеры — компонент `GlassOverlays`.

| Наложение | Как устроено | Где применять |
|---|---|---|
| Верхний глянец | верхняя половина с пологой дугой снизу, белый `.45 → .06` | кнопки, плашки, ленты |
| Диагональный блик | треугольник из верхнего левого угла | самоцветы, предметы |
| Полосы-отражения | широкая + узкая диагональные полосы, слабая полоса в нижнем углу | стеклянные панели, лёд |
| Внутренний ободок | контур на 90%, ярче сверху и снизу, тусклее посередине | панели, слоты, клетки |
| Сферический блик | эллипс сверху, серп отражённого света снизу, яркая точка | сферы, монеты, круглые кнопки |
| Блёстки снизу | свечение у нижнего края, россыпь точек, одна искра | награды, редкие предметы |
| Строчка-пунктир | контур на 84%, белый пунктир | пустой слот, место под предмет |
| Рамка выбора | белый контур по краю, 4 px | выбранная клетка или предмет |

Не больше двух наложений на элемент; наложение не меняет цвет под собой.

## Перевод в SVG этого проекта

| Шаг урока | Чем делаем |
|---|---|
| Силуэт | `polygon` / `path` одним цветом `-500` |
| Свет и тень | радиальный градиент со светом сверху-слева: `-100` (слабо) → `-500` → `-900` к краю |
| Рефлекс | обводка формы цветом `-300`, смещённая вверх-влево и обрезанная по форме (видна только снизу-справа) |
| Фактура | размытые эллипсы `grime-500` / `-900` на теневой стороне, обрезанные по форме |
| Блик | большой размытый эллипс `-100` + маленький белый внутри |
| Металл, кожа, мелкие предметы | фильтр мягкого рельефа `#puff` (рассеянный свет и блик) |
| Углубление | внутренняя стенка `stone-700` сверху-слева, дно `slate-900` смещено вниз-вправо |
| Свечение | размытая копия формы цветом `-300` / `-500` под предметом |
| Искры | четырёхлучевая звёздочка `#fff` на самом ярком блике |
| Рамка | золотая оправа: `gold-100 → gold-700`, фаска обратным градиентом, заклёпки, блик сверху |

## Правила для иконок этой игры

- Свет всегда сверху-слева, у всех иконок одинаково.
- Без чёрных обводок: объём — светом, тенью и рефлексом.
- Ничего не выступает за рамку иконки.
- Один фокус на иконку; он же самый яркий и насыщенный.
- Иконка должна читаться в 48 px: проверять силуэт и фокус на маленьком размере, мелкую фактуру при необходимости убирать.
- Цвета — только из токенов палитры; стихия задаётся её шкалой `-100 … -900`.
- Эффекты (свечение, искры) — последним слоем и умеренно.
