# Palette

Статичное превью палитры: два цвета фона, семь камней и цвета кнопок, иконок и текста.

| Группа | Токен | HEX | Зачем |
|---|---|---|---|
| Фон | `bg-canvas` | #131619 | холст, темнее панелей; нейтральный, не конкурирует с камнями |
| Фон | `bg-cell` | #20242A | ячейка поля и панель: на шаг светлее — видна сетка и «колодец» под фишкой |
| Камень | `gem-amber` | #F1A748 | Янтарь — квадрат |
| Камень | `gem-emerald` | #38AA23 | Изумруд — крест |
| Камень | `gem-holo` | #2FD0E2 | Голограмма — капля |
| Камень | `gem-azure` | #3461B3 | Лазурь — шестиугольник |
| Камень | `gem-amethyst` | #7C2F87 | Аметист — треугольник |
| Камень | `gem-magenta` | #D055C4 | Магента — круг |
| Камень | `gem-platinum` | #D2D7E0 | Платина — звезда |
| Кнопки | `ui-primary` | #F1A748 | действие (= Янтарь) |
| Кнопки | `ui-success` | #38AA23 | подтвердить |
