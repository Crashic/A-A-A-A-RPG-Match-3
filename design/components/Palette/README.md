# Palette

Статичное превью палитры: два цвета фона, семь камней и цвета кнопок, иконок и текста. Камни подобраны по яркости (luma 52 → 204 с шагом ~25) и насыщенности C* ≥ 50 — различимы даже в сером.

| Группа | Токен | HEX | Назначение |
|---|---|---|---|
| Фон | `bg-canvas` | #101318 | глубокий фон / холст |
| Фон | `bg-cell` | #1A1E25 | ячейка поля / панель |
| Камень | `gem-blue` | #121FFA | Синий — шестиугольник |
| Камень | `gem-red` | #E40D03 | Красный — круг |
| Камень | `gem-magenta` | #E411DA | Маджента — треугольник |

| Камень | `gem-cyan` | #1EF7E4 | Циан — капля |
