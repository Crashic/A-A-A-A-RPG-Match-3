# Palette

Палитра фишек: закатное небо, каменные панели, тёмные ячейки, семь камней в три тона (светлый / основной / тёмный) и цвета интерфейса и текста. Превью — живой образец: камни, поле 7×7, проверка в оттенках серого и при трёх типах дальтонизма, образцы интерфейса и **«Текст на цветах»** — выбор роли текста, своего текста и цвета текста с контрастом на каждом фоне.

## Контраст текста

- Светлый текст `text-primary` — на небе, камне, ячейках, ленте, кнопке «нет» (4,36:1 — только от 24 px или полужирный крупный).
- Тёмный текст `ui-outline` — на кнопке «да», золоте, пергаменте, аквамарине, топазе, жемчуге.
- Порог — 4,5:1 для обычного текста, 3:1 только для заголовков от 24 px.
