# Panels

Окна и HUD: фиолетовая лента с золотой кромкой, глянцем и раздвоенными хвостами над панелью в золотой раме, вдавленные блоки, выпуклые звёзды, золотая монета со звездой, счётчики, полоса здоровья.

- Монета и звёзды нарисованы по уроку монеты: ребро, ободок, фаска, рельеф, глянец, искра. Пустая звезда — каменная, без глянца.
- Вдавленный блок и награды: `slate-800` с внутренней тенью и ободком `gold-700`.

- Звёзды наград обрамлены золотыми крыльями; у полосы здоровья — выпуклое сердце `heart-*`.
- На всём — «Внутренний ободок» из `GlassOverlays`.
