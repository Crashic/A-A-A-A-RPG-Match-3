# Buttons

Кнопки в стиле пухлых леденцов: градиент `-300 → -500`, нижний бортик `-700`, кремовый текст с тенью.

- Зелёная — главное действие, красная — выход, оранжевая — награда, фиолетовая — магазин, каменная — второстепенное.
- Круглые кнопки-иконки 56 px; неактивная — обесцвеченная.
- Текст 22 px+ (на зелёной и оранжевой контраст ≈3.5:1 — только крупный текст).
