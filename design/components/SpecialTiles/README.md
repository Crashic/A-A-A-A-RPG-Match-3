# SpecialTiles

Спец-элементы: бонусы за длинные совпадения и препятствия, в тех же золотых оправах.

- Линия (4 в ряд) — стрелки поверх самоцвета; Взрыв (Г/Т из 5) — золотые искры вокруг; Призма (5 в ряд) — сфера из всех стихий.
- Цепи (контур `stone-900`) и лёд лежат поверх фишки; Валун — каменный блок без оправы, сразу видно препятствие.
