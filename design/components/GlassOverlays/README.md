# GlassOverlays

Набор стеклянных бликов, которые накладываются поверх любой иконки или элемента интерфейса — одинаково на двенадцать форм: квадрат, круг, сквиркл, шестигранник, восьмигранник, щит, сердце, ромб, каплю, арку, звезду и свиток. Блик всегда обрезан по форме элемента и не выходит за неё.

| Наложение | Как устроено | Где применять |
|---|---|---|
| Верхний глянец | верхняя половина, нижний край — пологая дуга; белый `.45 → .06` сверху вниз | кнопки, плашки, ленты |
| Диагональный блик | треугольник из верхнего левого угла, тот же градиент | самоцветы, иконки предметов |
| Полосы-отражения | широкая и узкая диагональные полосы `.16` / `.12`, слабая полоса в нижнем правом углу | стеклянные панели, лёд |
| Внутренний ободок | контур формы на 90%, белый: ярче сверху, тусклее посередине, снова ярче снизу | панели, слоты, клетки |
| Сферический блик | эллипс-блик сверху, серп отражённого света снизу, яркая точка | сферы рун, монеты, круглые кнопки |
| Блёстки снизу | мягкое свечение у нижнего края, россыпь точек и одна искра | награды, редкие предметы |
| Строчка-пунктир | контур формы на 84%, белый пунктир `4 / 3.5` | пустой слот, место под предмет |
| Рамка выбора | белый контур по краю формы, 4 px | выбранная клетка или предмет |

Правила:
- Не больше двух наложений на один элемент (например, диагональный блик + блёстки).
- Наложение — последний слой, после цвета, объёма и рельефа; цвет элемента под ним не меняется.
- Свет всегда сверху-слева, как у остальных иконок.

Формы и их назначение:

| Форма | Для чего |
|---|---|
| квадрат, сквиркл | кнопки-иконки, слоты инвентаря |
| круг | навыки, монеты, круглые кнопки |
| 6-гранник, 8-гранник | самоцветы, руны, ячейки талантов |
| щит | защита, гильдии, ранги |
| сердце | здоровье, жизни |
| ромб | редкие предметы и навыки |
| капля | зелья, мана |
| арка | карты навыков, портреты героев и врагов |
| звезда | достижения, рейтинг, бонусы |
| свиток | заголовки, подписи, награды |
