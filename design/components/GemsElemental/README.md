# GemsElemental

Вариант A (основной): семь фишек одной формы — **сквиркл** из `GlassOverlays` цвета камня. Внутри — простая иконка ресурса тёмным тоном того же камня (`gem-*-dark`, непрозрачность 55 %): заметна, но не спорит с цветом. Поверх — стиль **«Внутренний ободок»**.

| Камень | Иконка | Ресурс |
|---|---|---|
| Аметист | кассета с двумя бобинами | Плёнка / кассеты |
| Сапфир | двутавр | Металл / арматура |
| Рубин | канистра с горловиной и ручкой | Топливо / канистры |
| Изумруд | лист с прожилкой | Травы / листья |
| Аквамарин | шестерёнка | Детали / шестерёнки |
| Топаз | трилистник радиации | Радиационный маркер |
| Жемчуг | талон с вырезами и перфорацией | Документы / талоны |

- Камни различаются цветом и ступенью светлоты; иконка — вторая подсказка (дальтонизм, оттенки серого).
- Иконка занимает 56 % плитки, силуэт без мелких деталей — читается в 40 px.
- Превью проверяет фишки на 60, 48 и 40 px, на тёмном и на светлом участке фона.
