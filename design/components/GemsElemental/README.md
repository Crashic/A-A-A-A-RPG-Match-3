# GemsElemental

Вариант A (основной): семь фишек — чистые геометрические фигуры без скруглений, под реальный размер 40–60 px: тёмный кант, насыщенное тело и один блик, без внутренних рисунков.

| Камень | Форма | Заливка клетки |
|---|---|---|
| Рубин | круг | 46% |
| Янтарь | квадрат | 46% |
| Аметист | треугольник | 44% |
| Сапфир | правильный шестиугольник | 46% |
| Топаз | пятиконечная звезда | 39% |
| Голограмма | капля (круг + две касательные к острой вершине, переход плавный) | 43% |
| Нефрит | крест (плечи — треть стороны) | 46% |

- Углы острые, стороны прямые; кант с острыми стыками (miter).
- Звезда и капля легче остальных: чистая звезда физически занимает меньше площади, а при толстых лучах перестаёт быть звездой.
- **Кант** ≈ 2.5 px при 48 px: второстепенный цвет камня, затемнённый на 30%, лежит внутри контура — фишка не раздувается.
- **Тело** — основной цвет с внутренним градиентом (светлее сверху-слева, темнее снизу-справа) и тенью второстепенного цвета вдоль нижнего края.
- **Блик** — один белый эллипс сверху-слева. Внутренних рисунков, тонких линий и искр нет — на 40 px они превращаются в шум.
- Превью проверяет фишки на 60, 48 и 40 px, на тёмном и на светлом участке фона.
- На поле фишка ставится без оправы прямо в клетку.
