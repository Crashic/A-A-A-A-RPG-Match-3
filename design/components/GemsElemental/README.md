# GemsElemental

Вариант A (основной): семь фишек — чистые геометрические фигуры без скруглений, под реальный размер 40–60 px: плоская заливка цветом палитры, без обводки, бликов и внутренних рисунков.

| Камень | Форма | Заливка клетки |
|---|---|---|
| Гранат | круг | 46% |
| Янтарь | квадрат | 46% |
| Слива | треугольник | 44% |
| Лаванда | правильный шестиугольник | 46% |
| Орхидея | пятиконечная звезда | 39% |
| Небо | капля (круг + две касательные к острой вершине, переход плавный) | 43% |
| Изумруд | крест (плечи — треть стороны) | 46% |

- Углы острые, стороны прямые.
- Звезда и капля легче остальных: чистая звезда физически занимает меньше площади.
- Превью проверяет фишки на 60, 48 и 40 px, на тёмном и на светлом участке фона.
- На поле фишка ставится без оправы прямо в клетку.
