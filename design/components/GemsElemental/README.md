# GemsElemental

Вариант A: самоцвет стихии, утопленный в каменную плиту той же формы; без обводок, объём — светом и толщиной.

- Плита: тень, бортик `stone-900`, ободок `stone-100`, фаска `stone-700`, лицо `stone-500`, вдавленная панель `slate-900`/`slate-800` со свечением `-500`.
- Самоцвет: `-700` снизу, `-500` тело, `-300` верхняя грань, белый блик и искра `-100`. Без линий внутри.
- Ничего не выступает за контур; читается от 48 px.
