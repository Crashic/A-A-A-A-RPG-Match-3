# A-A-A-A Match 3 RPG

Мобильная match-3 RPG в браузере (PWA). Игра: https://crashic.github.io/A-A-A-A-RPG-Match-3/

Сейчас это каркас: открывается на телефоне во весь экран, ставится как приложение и сам подхватывает обновления. Игра делается с нуля.

## Структура

| Путь | Что внутри |
|---|---|
| `index.html` | разметка и подключение скриптов |
| `css/style.css` | стили интерфейса |
| `css/tokens.css` | цвета, отступы, радиусы (генерируется из `design/tokens.json`) |
| `css/fonts.css`, `fonts/` | шрифты Russo One и Nunito (OFL), работают офлайн |
| `design/` | копия дизайн-системы: правила стиля, палитра, гайд по иконкам, образцы элементов |
| `tools/` | `build-tokens.py` — токены в CSS, `update-sw.py` — список файлов кэша |
| `js/` | по одной функции на файл, имя файла = имя функции |
| `js/version.js` | номер версии (`APP_VERSION`) |
| `js/changelog.js` | список изменений, открывается нажатием на версию |
| `js/state.js` | общие переменные: число ячеек, настройки по умолчанию |
| `js/main.js` | точка входа, подключается последней |
| `sprites/` | спрайты игры |
| `sw.js` | офлайн-кэш и автообновление |
| `manifest.webmanifest`, `icon-*.png` | установка как приложение |

## Как выпустить обновление

1. Согласовать номер версии и текст изменений, выставить `APP_VERSION` в `js/version.js` и добавить запись сверху в `js/changelog.js`.
2. Новый скрипт подключить в `index.html` перед `js/main.js`, затем `python3 tools/update-sw.py` (обновит список кэша в `sw.js`).
3. Запушить в `main`. GitHub Pages обновится, а телефон при следующем открытии скачает новую версию и перезагрузится сам.
