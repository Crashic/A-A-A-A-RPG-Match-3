# A-A-A-A Match 3 RPG

Мобильная match-3 RPG в браузере (PWA). Игра: https://crashic.github.io/A-A-A-A-RPG-Match-3/

Сейчас это каркас: открывается на телефоне во весь экран, ставится как приложение и сам подхватывает обновления. Игра делается с нуля.

## Структура

| Путь | Что внутри |
|---|---|
| `index.html` | разметка и подключение скриптов |
| `css/style.css` | стили |
| `js/` | по одной функции на файл, имя файла = имя функции |
| `js/version.js` | номер версии (`APP_VERSION`) |
| `js/changelog.js` | список изменений, открывается нажатием на версию |
| `js/main.js` | точка входа, подключается последней |
| `sprites/` | спрайты игры |
| `sw.js` | офлайн-кэш и автообновление |
| `manifest.webmanifest`, `icon-*.png` | установка как приложение |

## Как выпустить обновление

1. Поднять `APP_VERSION` в `js/version.js` и добавить запись сверху в `js/changelog.js`.
2. Новый файл (скрипт, спрайт) добавить в список `FILES` в `sw.js`; скрипт — ещё и в `index.html` перед `js/main.js`.
3. Запушить в `main`. GitHub Pages обновится, а телефон при следующем открытии скачает новую версию и перезагрузится сам.
