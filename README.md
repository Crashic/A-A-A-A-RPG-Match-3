# Осколки Бездны

Мобильная match-3 RPG в браузере (PWA). Игра: https://crashic.github.io/A-A-A-A-RPG-Match-3/

## Структура

| Файл | Что внутри |
|---|---|
| `index.html` | разметка и подключение файлов |
| `css/style.css` | все стили, палитры, меню |
| `js/data.js` | палитры, базы предметов, аффиксы, уникалы, классы, самоцветы |
| `js/flasks.js` | флаконы, лавка, питомцы, дневные задания |
| `js/ascend.js` | подклассы 60 уровня |
| `js/tree.js` | древо навыков |
| `js/state.js` | состояние героя, достижения, сохранение |
| `js/atlas.js` | карты, Бесконечная Бездна |
| `js/items.js` | генерация предметов, крафт, умения |
| `js/enemy.js` | враги, боссы, смерть |
| `js/board.js` | поле, матчи, каскады, подсказки, ход |
| `js/popups.js` | окно выпавшего предмета, выбор самоцвета |
| `js/ui.js` | отрисовка интерфейса и вкладок |
| `js/input.js` | касания, перетаскивание, события |
| `js/start.js` | запуск и выбор класса |
| `js/pwa.js`, `sw.js`, `manifest.webmanifest` | установка как приложение, офлайн |

Скрипты подключаются по порядку (общая глобальная область), порядок в `index.html` менять нельзя.
`python3 build.py` собирает один файл `dist/abyss-shards.html`.
При добавлении файла добавьте его в список в `sw.js` и поднимите версию кэша.
